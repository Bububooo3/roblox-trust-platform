### CLIENT
#### (Browsing)
- Open platform
- Navigate to “Explore” page or search
- Sort and filter results by user data values
- Select user to navigate to their profile page
- View reviews, experience, and methods of communication
#### (Hiring)
- Navigate to target user profile
- Reach out to user through provided communication methods
- Initiate and mutually confirm a new transaction through the product once an agreement is made
#### (Cancelling)
- Navigate to target transaction page
- Request to cancel
- Wait for employee confirmation
- If employee does not confirm, both parties can still report each other but will be recommended to talk it out
#### (Completing)
- Navigate to target transaction page
- Request to confirm transaction complete
- Wait for employee confirmation
- Rate the the employee for this specific transaction through the pop-up (optional)
- If employee does not confirm, the transaction is left open until it is confirmed, cancelled, or reported

### EMPLOYEE
#### (Background Check)
- Search client by username or account id
- Navigate to their profile
#### (Cancelling)
- Navigate to target transaction page
- Request to cancel
- Wait for client confirmation
- If client does not confirm, both parties can still report each other but will be recommended to talk it out
